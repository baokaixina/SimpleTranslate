## Short / 短简介

### 中文

SimpleTranslate 是客户端 Minecraft 实时翻译模组，支持聊天、物品与悬浮提示、书本、告示牌、HUD、Patchouli/FTB 等模组 GUI，并为 Minecraft 1.21.4+ 提供 Wynncraft 专用对话与 Actionbar 支持。

### English

SimpleTranslate is a client-side real-time translator for chat, tooltips, books, signs, HUD, and mod GUIs such as Patchouli and FTB, with dedicated Wynncraft dialogue/actionbar support on Minecraft 1.21.4+.

## Repository subtitle / 仓库副标题

### 中文

Fabric、Forge、NeoForge 客户端实时翻译模组，覆盖 Minecraft 全场景文本、其他模组 GUI 与 Wynncraft。

### English

A Fabric, Forge, and NeoForge client-side translator for Minecraft text, mod GUIs, and Wynncraft.

## MC百科一句话

通过用户自备模型/API 实时翻译 Minecraft 聊天、物品、书本、告示牌、HUD 和模组 GUI，并在 1.21.4+ 提供 Wynncraft 专用支持。

## Important qualifier / 必要限定

### 中文

不内置免费翻译引擎或 API 额度；Fabric 1.12.2 为功能面较窄的 Legacy 版本；Wynncraft 专用功能仅限 Minecraft 1.21.4+。仅 Forge 1.12.2 需要另装 [MixinBooter 9.4+](https://github.com/CleanroomMC/MixinBooter)，SimpleTranslate 不打包该依赖。

### English

No free engine or API quota is bundled. Fabric 1.12.2 is a narrower Legacy build, and dedicated Wynncraft features require Minecraft 1.21.4+. Only Forge 1.12.2 requires [MixinBooter 9.4+](https://github.com/CleanroomMC/MixinBooter); SimpleTranslate does not bundle it.
