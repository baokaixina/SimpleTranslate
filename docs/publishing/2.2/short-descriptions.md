### English

### 中文

SimpleTranslate 2.2 —— GUI 一次性翻译、Scholar 书籍、命令消息

## Release summary / 更新摘要

### English

The GUI shortcut translates the current screen once instead of continuously. Scholar written books and book-and-quill screens can be translated, with edit-screen translation kept display-only so the saved book keeps your text. Outgoing slash commands are translated without touching command names, selectors, ids, or JSON keys, with a configurable list for server channel commands such as `/pc`. All 56 builds now share the version number 2.2.

### 中文

GUI 快捷键改为翻译当前界面一次，不再持续翻译。Scholar 的成书与书与笔界面可翻译，编辑界面的译文仅用于显示，保存的书里仍是你写的原文。发出的斜杠命令可翻译，且不改动命令名、选择器、ID 和 JSON 键名，服务器频道命令（如 `/pc`）由可配置列表覆盖。全部 56 个构建统一为版本号 2.2。

## Important qualifier / 必要限定

### 中文

不内置免费翻译引擎或 API 额度；Fabric 1.12.2 为功能面较窄的 Legacy 版本，且不含命令消息翻译；Wynncraft 专用功能仅限 Minecraft 1.21.4+；Scholar 支持仅限 1.20.1 及 1.21+ 目标，且 Scholar 为可选依赖。仅 Forge 1.12.2 需要另装 [MixinBooter 9.4+](https://github.com/CleanroomMC/MixinBooter)，SimpleTranslate 不打包该依赖。

### English

No free engine or API quota is bundled. Fabric 1.12.2 is a narrower Legacy build without command message translation. Dedicated Wynncraft features require Minecraft 1.21.4+. Scholar support covers 1.20.1 and 1.21+ targets, and Scholar itself is optional. Only Forge 1.12.2 requires [MixinBooter 9.4+](https://github.com/CleanroomMC/MixinBooter); SimpleTranslate does not bundle it.
